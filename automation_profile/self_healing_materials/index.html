How to turn on GPU

Chrome: Settings, System, switch on Use graphics acceleration when available, then relaunch. Open chrome://gpu and check that WebGPU says hardware accelerated.

Edge: the same setting is in edge://settings/system; check edge://gpu.

Linux Setup: Open chrome://flags, enable Vulkan (#enable-vulkan) and Force enable WebGPU interop (#force-enable-webgpu-interop), then relaunch[cite: 1].

Still unavailable? Update your graphics driver. On laptops with two GPUs, Windows Settings, System, Display, Graphics, then set the browser to High performance.

Then reload this page and tick the box. The GPU model is a bigger one-time download (about 330 MB). If GPU start-up fails, reload the page before trying the CPU again.
